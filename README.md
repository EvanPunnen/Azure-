# Azure Data Factory Data Pipeline

## Description

This project demonstrates the creation of a **cloud-based ETL data pipeline using Microsoft Azure Data Factory**. The pipeline is designed to extract data from **Azure Blob Storage**, configure datasets and linked services, and transfer the data to a destination storage location using a **Copy Data activity**.

The project covers the complete workflow, including Azure resource creation, storage account and container setup, data upload, Azure Data Factory configuration, source and destination datasets, pipeline creation, execution, and validation of successful data transfer.

## Technologies Used

* Microsoft Azure
* Azure Data Factory
* Azure Blob Storage
* Azure Resource Manager
* ETL / Data Integration
* Copy Data Activity

## Key Features

* Created Azure Resource Group and Storage Account
* Created Blob Storage containers for source and destination data
* Uploaded source files to Azure Blob Storage
* Created an Azure Data Factory instance
* Configured linked services
* Created source and destination datasets
* Built an ETL pipeline using Copy Data activity
* Executed and monitored the pipeline
* Verified successful data movement between storage locations

## Workflow

**Source Data → Azure Blob Storage → Azure Data Factory → Copy Data Activity → Destination Storage**

## Objective

The objective of this project is to gain practical experience with **cloud-based data integration and ETL workflows using Azure Data Factory**, including connecting storage services, configuring datasets, creating pipelines, and validating data movement.
